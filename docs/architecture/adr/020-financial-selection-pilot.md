# ADR 020 — Measure one closed-choice financial task through existing admission

26 October 2026. Accepted for the user-authorized local pilot; no serving/deployment.

The named owning package is now [Sprint 12.1](../../03-sprints/active/sprint-12.1/README.md).
Its [run record](../../03-sprints/active/sprint-12.1/RUN_RECORD.md) separates prepared
state, approved demo grants, explicit automated provenance and actual provider
results. The owner approved one local synthetic-only audit; human review remains
false. Live fixture acceptance is unmet after f02 TIMEOUT.

Current Gemini/Puter/Groq keys support limited guided selection. Broad AT17 has
failed/unmeasured semantic evidence and cannot be cleared by enabling profiles.
Existing historical cloud benchmark tools have separate authorization/usage ledgers;
reusing them would risk bypassing the current shared account budget.

Use one explicit financial observation-selection rule and 12 original numeric
fixtures (six calibration, six reserved). Require a second authorized human to
review the rule-derived labels by default. The later owner-approved exception
uses exact Fraction arithmetic for only the pinned original corpus, on a default-off
local one-UUID allowlist. Store automated_rule_audit with human_reviewed=false;
retain every Admin/project/grant check and the human path for other pilots.
Freeze corpus/prompt/policy/model,
reconstruct results from existing AI runs/calls/sections, and preserve every attempt.
The UI supports preparation, review, one-case execution, history and report download.
Add one tenant table in forward migration 0019; retain ordinary jobs, provider
admission, scoped source checks and fallback behavior.

This deliberately evaluates only the already approved numeric input/ID-output
contract. It needs no expanded document/personnel egress, new key, hosted training
or extra infrastructure. It does not qualify financial interpretation: deterministic
code already solves the rule, and no supported non-template interpretation is added.
Even a perfect fixture run returns AT17 BLOCKED and cannot activate a semantic
profile. Broader evaluation remains a separately authorized scope/label/quality step.

Consequences: the application is usable with current APIs while limits are visible;
real measurements require the applicable explicit review provenance and available shared quota. Synthetic
results remain separate from real evidence. Provider outages/unknown outputs stop
the pilot without retry or ledger reset. Production-sized evaluation, provider version
stability and reviewer/retention ownership stay in the deployment register.
