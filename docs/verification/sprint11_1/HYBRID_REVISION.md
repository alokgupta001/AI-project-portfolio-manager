# Hybrid-role blueprint revision

17 October 2026. User authorization: “ok then update it”, followed by “retry”. Scope: revise Sprint 11.1 architecture documentation to combine deterministic services with on-demand AI interpretation across all nine roles. No application code, dependencies, generated API contracts, migrations, provider settings or normal data were changed by this revision.

## Changes and consistency review

- ADR 11.1-11 supersedes the initial permanent role split. All nine catalog entries declare qualified interpretation paths, triggers, task classes, evidence, fallback and tests. Python retains authoritative calculations, scoring, privacy, routing, validation and execution.
- Financial/schedule/resource can interpret authorized explanatory text alongside canonical numbers. PMO/Executive can synthesize accepted findings with original source support. Sentiment retains the current aggregate-only boundary and never gains raw personnel notes or emotional diagnosis.
- Request modes and ordered role priority guide the ≤3 initial sections; requested synthesis slots are reserved in that budget. Four total attempts, 512 output tokens, 90-second deadline, 24-node ceiling and local concurrency one remain unchanged.
- Each role reports baseline versus semantic outcomes and coverage. Requested work lacking a slot is deferred; a successful numerical template does not mark AI reasoning complete. A nine-role interpretation request can still be partial.
- New synthesis-mode output uses accepted basis aliases and exact original evidence. Downstream context binds once after upstream results exist, with its own resolved hash. Model synthesis cannot modify numbers, hide conflicts, widen scope or become an independent source.
- Diagrams, provider task-class eligibility, schema/persistence contracts, implementation tasks, benchmark corpus, traceability, setup, risk register, tracker and handover were reconciled. Model qualification is per class; the proposed corpus now has at least 108 cases across nine classes, and no live quality claim is made.
