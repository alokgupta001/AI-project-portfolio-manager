# Canonical master prompt entry point

Read and apply [01-MASTER-PROMPT.md](01-MASTER-PROMPT.md). This pointer preserves the original prompt pack without maintaining a second editable copy of its instruction text.

Read [LATEST.md](../handoffs/LATEST.md) and [decisions and assumptions](../requirements/decisions-and-assumptions.md) before each sprint.
