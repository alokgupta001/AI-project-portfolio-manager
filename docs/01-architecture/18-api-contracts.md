## Authentication, validation and errors

Routes use live cookie/session/membership checks, organization RLS and owning-domain permissions. Mutations require CSRF/Origin except explicitly signed provider hooks. OpenAPI does not enumerate grants or privacy rules: read the [permission contract](../contracts/permissions.md) and [document contract](../contracts/documents.md). Ownership grants no access. `main.error_response` returns sanitized code/message/request_id/details. Revisions, idempotency, rate limits and dependency failures remain handler-specific.

Document original downloads additionally need a 60-second signed ticket and current authenticated authority; source bytes are SHA-256 verified. See [the practical trace](../02-learning/06-ai-and-analytics/DOCUMENT_SOURCES.md).
