# API reference — actual current routes

Source-reviewed 9 October 2026. Generated from `main.create_app().openapi()` and actual route endpoints **without running lifespan, accessing settings secrets or contacting databases/providers**. ## Authentication, validation and errors

Authenticated routes depend on `identity.principal`/Auth and current organization membership/RLS. Browser cookies are `ppm_access`/`ppm_refresh`; state-changing requests require configured Origin plus CSRF cookie/header except the specifically signed GitHub hook. Public challenge/auth routes still follow their own CSRF/rate-limit rules. Read each linked handler and [permission contract](../contracts/permissions.md) for exact role/grant/assignment requirements: OpenAPI alone does not enumerate all authorization rules. Ownership never bypasses grants; private effort/assessment answers need their own access.

`main.error_response` emits `error` with code, message, request_id and details. Pydantic validation returns 422; identity, denial, not-found, revision conflict and 503 dependency cases depend on the route. Error messages are sanitized; no credentials/challenge payload is a public response. Generic reset/registration requests resist enumeration. Nullable/missing values and decimal serialization follow actual schemas.
