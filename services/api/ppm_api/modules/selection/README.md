# Selection

Explicitly scoped financial-selection fixture research and label review.

| File | Responsibility |
| --- | --- |
| [__init__.py](__init__.py) | Package description with no eager exports |
| [audit.py](audit.py) | Bounded pilot lineage/audit rules |
| [protocol.py](protocol.py) | Versioned authored fixture protocol, source packing and strategy summaries |
| [router.py](router.py) | Thin HTTP adapters, request/response metadata and delegation to business operations |
| [schemas.py](schemas.py) | Validated feature inputs and public response models |
| [service.py](service.py) | Scoped pilot lifecycle, binding/revision checks, independent label review and fixture measurement |
| [tables.py](tables.py) | Selection-pilot state and reviewed lineage |

This is isolated fixture research. Moving code does not execute a pilot, accept labels, enable inference or expand grants. Source prompts, quotas, lineage and independent-review rules remain.
